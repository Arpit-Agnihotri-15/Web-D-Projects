# Amazon Clone Project

A modern Amazon-inspired frontend web application built using React and Vite.

## Tech Stack

- React + Vite
- Bootstrap
- Tailwind CSS
- React Router DOM

## Features

- Responsive homepage
- Product cards
- Product details page
- Cart functionality
- Login page
- Toast notifications
- Smooth navigation

## Project Status

Project is currently under development.

## Run Locally

```bash
npm install
npm run dev
